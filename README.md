# Genesis Roofing & Repair website

This folder is a snapshot of the working static website after the September 29, 2026 homepage photo-link update. It is ready for static hosting: `index.html` is at the root and the other pages and assets retain the same paths as the deployed ZIP.

## Updating the website

Edit the relevant HTML page and image under `images/`, then check that every local image and page link resolves. Upload the full contents of this folder for a direct Cloudflare Pages deployment. Keep the repository and deployed package in sync after each change.

This snapshot contains built static files. It does not include the Astro project source or a build script; the GitHub repository previously contained only its initial README. Do not assume an Astro build will reproduce these pages until source files have been restored or rebuilt.
